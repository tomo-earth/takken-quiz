# 現場日報アプリ 手順書（自己更新版・2026-09-08）

これが**最後の貼り付け**です。今日の作業を終えると、以後は Claude が GitHub に新版を置き、
Apps Script の「更新」を1回実行するだけ（または毎日自動）で、コード更新・公開・マスター修正が全部自動になります。

## 今日やること（約15分）

### 1. コードを貼り替える（3分）
Apps Script を開く → コードの中を **Ctrl+A → Delete** → `現場日報アプリ_全部入り.txt` をメモ帳で開き **Ctrl+A → Ctrl+C** → **Ctrl+V → Ctrl+S**

### 2. 設定ファイル（appsscript.json）を貼り替える（3分）
1. 左の **歯車 ⚙（プロジェクトの設定）** → 「**「appsscript.json」マニフェスト ファイルをエディタで表示する**」に ✔
2. 左の「**< >**」（エディタ）に戻ると、ファイル一覧に **appsscript.json** が出るのでクリック
3. 中身を **Ctrl+A → Delete** → 下の内容をそのまま貼り付け → **Ctrl+S**

```json
{
  "timeZone": "Asia/Tokyo",
  "dependencies": {},
  "exceptionLogging": "STACKDRIVER",
  "runtimeVersion": "V8",
  "oauthScopes": [
    "https://www.googleapis.com/auth/spreadsheets",
    "https://www.googleapis.com/auth/drive",
    "https://www.googleapis.com/auth/script.external_request",
    "https://www.googleapis.com/auth/userinfo.email",
    "https://www.googleapis.com/auth/script.projects",
    "https://www.googleapis.com/auth/script.deployments",
    "https://www.googleapis.com/auth/script.scriptapp"
  ],
  "webapp": {
    "executeAs": "USER_DEPLOYING",
    "access": "DOMAIN"
  }
}
```

### 3. Google Apps Script API を ON にする（1分・1回だけ）
新しいタブで **https://script.google.com/home/usersettings** を開き、**「Google Apps Script API」を オン** にする

### 4. 「更新」を実行（3分）
1. エディタの「コード.gs」に戻り、関数の▼で **「更新」** を選んで **▶実行**
2. 「承認が必要です」→ 権限を確認 → 自分のアカウント → 詳細 → …に移動 → **許可**
   （新しい権限が増えたので、もう一度この画面が出ます）
3. 実行ログに次のように出れば完了：
   - コードを 2026-09-08-1 に更新しました
   - アプリを新バージョンで公開しました。URL は変わりません
   - ✅ 工種「外構工事」の工程を修正／✅ 工種「内部大工」を追加／✅ 集計シートに◯日分の行を追加／✅ 社員の割り当て表を追加

これで **公開範囲も「組織内の全員」に自動で変わります**（デプロイ画面の操作は不要）。

### 5. （任意）毎日自動で更新したい場合
関数の▼で **「自動更新をON」** → ▶実行。毎朝5時ごろに GitHub の新版を自動で取り込みます。
止めるときは「自動更新をOFF」。
