# 現場日報アプリ 公開手順書（友寄様用・所要 約20分）

このフォルダの3ファイル（`コード.gs`／`index.html`／`appsscript.json`）と
`現場日報_台帳_クラウド版.xlsx` を使います。作業は友寄様の会社アカウントで行ってください。

## 前提

- 社員全員が共有ドライブ「アース建設03案件」（の 00.工事部）を開けること
  （台帳への書き込みと写真保存を、アクセスした本人の権限で行うため）

## 手順1：台帳スプレッドシートを作る（約5分）

1. `現場日報_台帳_クラウド版.xlsx` を Google ドライブの **00.工事部** フォルダへドラッグ＆ドロップ
2. アップロードしたファイルをダブルクリックで開く → 上部メニュー **ファイル → Google スプレッドシートとして保存**
3. 変換されたスプレッドシートが開く。**検算**：シート「日別集計」の合計行（141行目）の合計が **276**、
   自社 180／業者 96 になっていること（Excel と同じ数字なら移植成功）
4. ブラウザのURL `https://docs.google.com/spreadsheets/d/～ここがID～/edit` の **ID部分をコピー**して控える
5. 元の .xlsx ファイル（変換前）は紛らわしいので削除するか、名前に「（取込済み原本）」を付けて残す

※ シート「設定」に写真フォルダのIDが入っています（変更不要。現場を増やす時にここへ行を足します）。

## 手順2：Apps Script を貼り付ける（約10分）

1. 手順1のスプレッドシートを開いた状態で、メニュー **拡張機能 → Apps Script**
2. 左側の「コード.gs」を開き、中身を**全部消して** `コード.gs` の内容を貼り付け
3. 貼り付けた先頭付近の `SPREADSHEET_ID = 'ここに…'` に、手順1-4で控えた **ID を貼る**
4. エディタ左上の **＋ → HTML** でファイルを追加し、名前を **index** にして、
   中身を**全部消して** `index.html` の内容を貼り付け
5. 左の歯車（プロジェクトの設定）→「**appsscript.json をエディタで表示する**」にチェック
   → 左に出た appsscript.json を開き、中身を `appsscript.json` の内容に**丸ごと差し替え**
6. フロッピーアイコンで全ファイル保存

## 手順3：ウェブアプリとして公開（約5分）

1. 右上 **デプロイ → 新しいデプロイ**
2. 歯車で種類 **ウェブアプリ** を選択
   - 説明：現場日報 v1
   - 実行ユーザー：**ウェブアプリにアクセスしているユーザー**
   - アクセスできるユーザー：**（会社の組織名）内の全員**
3. **デプロイ** → アクセス承認の画面が出たら自分のアカウントで **許可**
4. 表示された **ウェブアプリのURL** をコピー（これがアプリのアドレス。社員に配るのはこのURL）

## 手順4：動作確認チェックリスト

スマホ（会社アカウントでログインした Chrome / Safari）でURLを開いて：

- [ ] 初回にGoogleのログイン・許可画面が出て、その後ホーム画面が出る（右上に自分の名前）
- [ ] 「＋今日の日報を入力」→「＋作業を追加」→ 自社で作業員を2人選んで追加 →
      業者でもう1件追加 → 「確認へ進む（3行）」と行数が出る
- [ ] 📷で写真を1枚付けて送信 → 「台帳に3行追加しました・写真1枚保存」と出る
- [ ] スプレッドシートの台帳末尾に3行入っている（B列曜日・E列工程が自動で入っていればOK）
- [ ] ドライブの 01_谷直美様邸 → 06_写真 → 日報 → 2026-09 に写真が入っている
- [ ] 現場を変えた場合（マスターに無い現場等）の写真が 99_写真置き場（現場不明）に入る
- [ ] 「じぶんの履歴」で 3日前（アプリ導入前の日は「現場全体」に切替）が見られる
- [ ] テストで入れた行を台帳から削除して掃除する

つまずいたら、その画面のスクリーンショットを Claude に送ってください。

## 手順5：社員への配布

- ウェブアプリのURLを社内グループ等で共有し、**ホーム画面に追加**してもらう
  （iPhone：共有ボタン→ホーム画面に追加／Android：メニュー→アプリをインストール）
- 会社ロゴをアイコンにした「アプリらしい入口」は、ロゴ画像を受け取り次第 Claude が別途作成します

## 修正・改良したいとき

このフォルダのファイルが原本です。修正は Claude に依頼 → 修正版を再度貼り付け →
**デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン「新バージョン」→ デプロイ**
（URLは変わりません）
