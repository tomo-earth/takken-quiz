# 現場日報アプリ 公開手順書（かんたん版・所要 約10分）

必要なファイルは **`現場日報アプリ_全部入り.gs` の1つだけ**です。
台帳の変換・設定・IDの登録はすべてスクリプトの「セットアップ」が自動で行います。

> 前提：`07.日報フォルダ` に台帳の Excel（谷直美様邸_現場日報台帳_集計.xlsm など）が入っていること
> （すでに入っています。そのままで大丈夫。Google スプレッドシートへの変換は自動です）

## 手順1：スクリプトを作る（貼り付け1回）

1. パソコンのブラウザで **https://script.google.com/home** を開く（会社アカウントで）
2. 左上の **「＋ 新しいプロジェクト」** を押す
3. 真ん中に `function myFunction() {…}` と書かれた編集画面が出る。
   その中をクリック → **Ctrl + A（全選択）→ Delete** で空にする
4. `現場日報アプリ_全部入り.gs` をメモ帳で開き、**Ctrl + A → Ctrl + C** で全部コピー
5. 編集画面に戻り **Ctrl + V** で貼り付け → **Ctrl + S** で保存
6. 左上の「無題のプロジェクト」をクリックして名前を **現場日報アプリ** に変更

## 手順2：セットアップを実行（自動処理）

1. 編集画面の上にあるツールバーで、関数の選択（「myFunction」などと表示された▼）を **「セットアップ」** にする
2. その左の **▶ 実行** を押す
3. 「承認が必要です」と出たら **権限を確認 → 自分のアカウントを選択 →（詳細を表示 →）許可** と進む
   ※「このアプリは確認されていません」と出るのは自作スクリプトの標準の警告です。
   　「詳細」→「現場日報アプリ（安全ではないページ）に移動」→「許可」で進めます
4. 画面下の **実行ログ** に「✅ セットアップ完了。台帳: https://docs.google.com/…」と出れば成功
   （07.日報フォルダ に **「現場日報_台帳（アプリ用）」** というスプレッドシートが自動で作られます）

## 手順3：ウェブアプリとして公開（4クリック）

1. 右上の **デプロイ ▼ → 新しいデプロイ**
2. 左の歯車 → **ウェブアプリ**
3. 次のように設定
   - 説明：現場日報 v1
   - 次のユーザーとして実行：**ウェブアプリにアクセスしているユーザー**
   - アクセスできるユーザー：**（会社名）内の全員**
4. **デプロイ** を押す → 表示された **ウェブアプリの URL** をコピー（これがアプリのアドレス）

## 手順4：スマホで動作確認

会社アカウントでログインしたスマホのブラウザで URL を開いて：

- [ ] ロゴ付きのホーム画面が出て、右上に自分の名前が出る
- [ ] 「＋今日の日報を入力」→「＋作業を追加」→ 自社2人＋業者1件 → 「確認へ進む（3行）」
- [ ] 📷で写真1枚を付けて送信 → 「台帳に3行追加しました・写真1枚保存」
- [ ] 「現場日報_台帳（アプリ用）」の台帳末尾に3行入り、B列曜日・E列工程が自動で入る
- [ ] ドライブ 00.工事部 → 01_谷直美様邸 → 06_写真 → 日報 → 2026-09 に写真がある
- [ ] 「じぶんの履歴」で3日前が見られる（導入前の日は「現場全体」に切替）
- [ ] テスト行を台帳から削除

つまずいたら、その画面のスクリーンショットを Claude に送ってください。

## 社員への配布

- ウェブアプリのURLを社内で共有し、ホーム画面に追加してもらう
  （iPhone：共有 → ホーム画面に追加／Android：メニュー → ホーム画面に追加）
- ホーム画面のアイコンが Google 標準のままになる端末があれば Claude に連絡（ロゴを確実に出す入口を用意します）

## 修正版に差し替えるとき

Claude から新しい `現場日報アプリ_全部入り.gs` を受け取ったら：
編集画面で **Ctrl + A → Delete → 貼り付け → Ctrl + S** → 右上 **デプロイ → デプロイを管理 → 鉛筆 → バージョン「新バージョン」→ デプロイ**
（URL は変わりません。セットアップの再実行も不要です）
